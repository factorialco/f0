# Sidebar chat list

Sidebar chat list presents grouped conversations inside the application sidebar, including live presence, conversation statuses, unread activity, loading states, and pinning controls.

**Do's and don'ts**

<DoDonts
  do={{

      "Expose each independent state supplied by the communications service.",

  dont={{

      "Do not collapse unrelated states into one priority indicator.",
    guidelines: [

      "Do not pass duplicate statuses with the same meaning",
    ],

### Behavior

- WHEN `statuses` contains several entries → THEN every icon renders in array order with its own accessible label
- WHEN both `status` and `statuses` are provided → THEN `statuses` takes precedence
- WHEN `unreadCount` is greater than zero → THEN the row uses stronger text and displays the unread badge
- WHEN a group is collapsed with unread messages → THEN its heading displays the total unread count
- WHEN `loading` is true and there are no known chats → THEN the whole-list skeleton replaces the empty state
- WHEN an individual chat has `loading: true` → THEN only that row becomes a skeleton

### Screen reader behavior

- Conversation rows are buttons and expose their selected state through `aria-pressed`
- Online presence, each status icon, unread counts, and mention badges expose text alternatives
- Pin and unpin controls use localized action labels
- Loading rows are non-interactive until their identity resolves
