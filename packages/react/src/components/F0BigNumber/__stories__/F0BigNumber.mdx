# BigNumber

Presents a single headline metric — headcount, payroll cost, absence rate — with
an optional comparison against a previous period and the percentage change
between the two. For the shape of a metric over time use `LineChartWidget` or
`AreaChartWidget`; for the change on its own, inside a table cell or a dense
list, use `F0TagBalance`.

The rendered output has three parts, stacked and then wrapped on narrow
containers:

- **Label line** — the metric name, plain text above the figure.
- **Value** — the formatted figure, bold and larger than everything around it.
- **Balance tag** — `F0TagBalance` with the direction arrow, the percentage and
  the comparison amount joined by a middle dot, plus `comparisonHint` as sibling
  text outside the tag.

Loading is a static sub-component, not a prop: render `<F0BigNumber.Skeleton />`
while the figure is being fetched.

### Content best practices

- Name the metric and its scope in `label`, in sentence case and with no period
  - **Correct:** "Payroll cost", "Absence rate", "Headcount · Engineering"
  - **Incorrect:** "Total", "TOTAL PAYROLL COST", "This is the payroll cost."
- Keep `comparisonHint` to a short prepositional phrase naming the baseline
  - **Correct:** "vs last month", "vs Q3", "vs same month last year"
  - **Incorrect:** "comparison", "compared to the previous month of the current
    fiscal year"
- Put currency and units in `value.units` with `unitsPosition`, not in the label
  text
  - **Correct:** `label: "Payroll cost"` with
    `value: { value: 1284000, units: "€", unitsPosition: "prepend" }`
  - **Incorrect:** `label: "Payroll cost in euros (€)"`

### Behavior

- WHEN `comparison` resolves to a number → THEN the balance tag renders next to
  the value. WHEN it resolves empty → THEN only the label and the value render,
  and `comparisonHint` is dropped with it.
- WHEN `trend` is `true` or `{ show: true }` and both `value` and `comparison`
  resolve to non-zero numbers → THEN the tag shows
  `((value - comparison) / comparison) * 100` with an up or down arrow.
- WHEN the baseline is `0` (or the value is `0`) → THEN the percentage is
  silently dropped and the tag renders neutral with the comparison amount only.
  A metric that starts a period at zero shows no growth figure, so state the
  baseline in `comparisonHint` rather than relying on the percentage.
- WHEN `trend` is omitted or `false` → THEN the comparison amount still renders
  in the tag, with no percentage and no arrow.
- WHEN `invertStatus` is `true` → THEN only the color flips. The arrow keeps
  following the sign of the change, so a decrease still points down while being
  colored as a positive result.
- The value is formatted to at most 2 decimal places and the percentage to 0, so
  the percentage is a rounded summary and never a precise figure.
- Number formatting follows the locale from `L10nProvider`, which defaults to
  English separators when no provider is present.
- `animated` on `NumberWithFormatter` is accepted by the type but never read —
  it has no effect on rendering.

### Usage examples

**Comparison without a trend**

Show the previous period's figure next to the current one when the raw baseline
is what matters and a percentage would over-dramatize a small absolute change.

<Canvas of={Stories.WithComparison} />

```tsx
<F0BigNumber
  label="Payroll cost"
  value={{ value: 1284000, units: "€", unitsPosition: "prepend" }}
  comparison={{
    numericValue: { value: 1197500, units: "€", unitsPosition: "prepend" },
  }}
  comparisonHint="vs last month"
/>
```

**Period-over-period change**

Set `trend` when the direction and size of the change are the point — a
dashboard tile that has to answer "is this going up or down?" at a glance.

<Canvas of={Stories.WithTrend} />

```tsx
<F0BigNumber
  label="Headcount"
  value={412}
  comparison={{ numericValue: { value: 388 } }}
  comparisonHint="vs last quarter"
  trend
/>
```

**Metrics where a decrease is good**

Absence rate, voluntary turnover, overtime hours and time to hire all improve
when they fall. Pass `invertStatus` so the drop is colored as a positive result
while the arrow still points down.

<Canvas of={Stories.WithTrendInvertStatus} />

```tsx
<F0BigNumber
  label="Voluntary turnover"
  value={{ value: 4.1, units: "%", unitsPosition: "append" }}
  comparison={{
    numericValue: { value: 5.6, units: "%", unitsPosition: "append" },
  }}
  comparisonHint="vs last quarter"
  trend={{ show: true, invertStatus: true }}
/>
```

**Loading state**

Render the skeleton while the figure is being fetched so the tile keeps its
height and the dashboard does not shift when the data lands.

<Canvas of={Stories.Skeleton} />

```tsx
function PayrollCostTile({ isLoading, cost, previousCost }: Props) {
  if (isLoading) {
    return <F0BigNumber.Skeleton />
  }

  return (
    <F0BigNumber
      label="Payroll cost"
      value={{ value: cost, units: "€", unitsPosition: "prepend" }}
      comparison={{
        numericValue: {
          value: previousCost,
          units: "€",
          unitsPosition: "prepend",
        },
      }}
      comparisonHint="vs last month"
      trend
    />
  )
}
```

## Accessibility

- `label` renders as a plain `<div>` with no heading semantics and no
  programmatic association with the value — the two are only related by DOM
  order. On a dashboard holding several metrics, give each tile a heading or
  label its container so screen reader users can move between metrics instead of
  hearing a run of bare numbers.
- The trend is not communicated by color alone: the balance tag renders an
  sr-only "positive balance" / "negative balance" / "neutral balance" string
  next to its text. That string is not translated and does not name the metric,
  so do not treat it as the metric's description.
- `comparisonHint` renders as visible sibling text inside the same flow and is
  announced in order after the tag. BigNumber never uses a tooltip for it, so
  nothing here depends on hover.
- The percentage is rounded to whole numbers. Do not make it the only place a
  precise figure appears — put the exact value in the headline figure or in the
  surrounding table.
- `F0BigNumber.Skeleton` renders decorative placeholders with a `cursor-progress`
  cursor and sets no `aria-busy` and no live region. Announce the pending state
  at the container level, for example `aria-busy` on the widget that swaps the
  skeleton for the figure.
