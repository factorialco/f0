## Guidelines

### Usage examples

#### Removable

Chips can optionally be made removable by setting the `onClose` prop.

<Canvas of={ChipStories.WithClose} />

When a chip is both clickable and removable, its primary and removal actions
remain separate.

<Canvas of={ChipStories.ClickableAndRemovable} />

#### With avatars

Chips can optionally display an avatar by setting the `avatar` prop.

<Canvas of={ChipStories.WithAvatar} />

#### With deactivated avatar and label

Chips can optionally display a deactivated avatar and label by setting the
`deactivated` prop.

<Canvas of={ChipStories.WithDeactivatedAvatarAndLabel} />

#### With an icon

Chips can optionally display an icon by setting the `icon` prop.

<Canvas of={ChipStories.WithIcon} />

## Accessibility

Clickable and removable chips render their actions as sibling buttons. The
removal button keeps the name "Close" and exposes the chip label as its
accessible description.
