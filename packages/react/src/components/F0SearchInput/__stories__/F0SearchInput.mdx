# F0SearchInput

Provides a compact search field with an optional clear action, minimum query
length, and delayed batched updates. Use `F0TextInput` when the field needs a
visible label, hint, validation message, or non-search text.

## Anatomy

<Canvas of={Stories.Default} />

- **Search icon**: Identifies the field as a search control.
- **Input area**: Native search input with an `aria-label` derived from its placeholder.
- **Clear button**: Appears when `clearable` is enabled and the query is not empty.

### Behavior

- WHEN the first query meets `threshold` → THEN a `debounceTime` delay starts.
- WHEN more qualifying changes arrive during that delay → THEN they replace the buffered query without restarting the delay.
- WHEN the delay ends → THEN `onChange` receives the latest buffered query.
- WHEN the query is cleared → THEN `onChange("")` runs regardless of `threshold` and focus returns to the searchbox.
- WHEN focus leaves after typing → THEN a pending delayed change does not move focus back.
- WHEN `disabled={true}` → THEN editing and keyboard focus are disabled.
- WHEN `loading={true}` → THEN the searchbox is marked busy and displays a loading indicator.

### Focus management

- `autoFocus` focuses the searchbox when it mounts but does not trap focus there.
- Clearing returns focus to the searchbox so typing can continue.
- Delayed updates never move focus after it has left the searchbox.

### Screen reader behavior

- The input exposes `role="searchbox"` and an `aria-label` derived from `placeholder`. When no placeholder is provided, the accessible name is `"Search"`.
- The clear button is announced as `"Clear"`.
- Loading sets `aria-busy` on the searchbox; disabled state uses the native `disabled` behavior and `aria-disabled`.
