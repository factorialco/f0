# AvatarFlag

The avatar for a country or locale.

---

## Overview

### Purpose

- Represent a country, region or locale by its flag
- Make locale-specific items recognizable at a glance

### Anatomy

A flag avatar is square and displays the flag image for the given country or
region code.

### Variants

#### Badge

`badge` overlays a marker on the bottom-right corner. It takes one of two
shapes: `{ type: "module", module }` renders a module avatar, and
`{ type, icon }` renders an icon badge in one of the `Badge` types (`neutral`,
`highlight`, `positive`, `critical`, `warning`). Both accept an optional
`tooltip`, shown on hover over the badge.

## Guidelines

### Design best practices

#### When to use

- The entity is always a country, region or locale
- Language and region pickers, localized content, nationality fields

#### When NOT to use

- The entity type is dynamic: use `F0Avatar`
- The entity is not a country/locale: use the matching `F0Avatar*` component

## Behavior

### Country code lookup

`flag` takes an ISO 3166-1 alpha-2 code, and the code drives two independent
lookups with different case rules:

- The **flag graphic** lookup is case-insensitive: `es`, `ES` and `Es` all
  resolve to the same flag.
- The **country name** lookup, which feeds the initials behind the graphic, is
  case-sensitive and only matches lowercase codes. Pass `es`, not `ES`, or the
  name falls back to the raw string you passed.

<Canvas of={FlagStories.CodeLookup} />

When the code resolves no flag, no graphic renders and the initials box is what
you see: the first two characters of whatever was passed (one character at `xs`
and `sm`, which take a single initial).

## Accessibility

The avatar is decorative by default: unless you pass `aria-label` or
`aria-labelledby`, the avatar box renders `aria-hidden` and screen readers skip
it. A `badge` is a sibling of that box rather than a child, so it is not covered
by the same `aria-hidden` — see the badge bullet below.

- In a row or a picker where the country name is already text, leave the label
  off and let that text carry the meaning. A labelled avatar next to the same
  word is announced twice.
- When the flag stands alone — a locale-only cell, a compact switcher — pass
  `aria-label` with the country name so it is reachable at all.
- `aria-labelledby` takes the **id** of the element holding the name, not the
  name itself.
- The avatar is `role="img"`, so its accessible name comes only from
  `aria-label`/`aria-labelledby`. The initials are never part of the name, no
  matter which country code produced them.
- The badge reaches no one: a module badge is hardcoded `aria-hidden`, and an
  icon badge exposes no accessible name. If the badge carries meaning, fold it
  into the `aria-label` too.
