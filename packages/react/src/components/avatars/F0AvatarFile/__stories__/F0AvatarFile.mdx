# AvatarFile

The avatar for a file or document.

---

## Overview

### Purpose

- Represent a file or document at a glance
- Communicate the kind of file through an icon derived from its type

### Anatomy

A file avatar is square and shows an icon derived from the file's name and MIME
type, so the file kind is recognizable without opening it. It is available in
sizes `xs`–`lg`.

#### File types

## Guidelines

### Design best practices

#### When to use

- The entity is always a file or document
- File lists, attachments, upload previews

#### When NOT to use

- The entity type is dynamic: use `F0Avatar`
- The item is not a file: use the matching `F0Avatar*` component
#### Do's and don'ts

<DoDonts
  do={{
    description:
      "Pass the stored filename and MIME type, so the type icon and the label agree.",
    guidelines: [
      "Read name and type straight off the upload record",
      "Keep the extension visible in the surrounding text too",
    ],
    children: (
      <F0AvatarFile
        file={{ name: "payroll-january-2026.pdf", type: "application/pdf" }}
        size="lg"
      />
    ),
  }}
  dont={{
    description: "Don't swap the filename for a friendly label.",
    guidelines: [
      'Without the extension the icon drops to a generic file',
      "Don't infer type from the label — take it from the file",
    ],
    children: <F0AvatarFile file={{ name: "Payroll", type: "" }} size="lg" />,
  }}
/>
