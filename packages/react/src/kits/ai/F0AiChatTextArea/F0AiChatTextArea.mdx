# F0AiChatTextArea

The AI composer accepts text, mentions, dictation, and file attachments. The host supplies upload and submit functions.

<Canvas of={Stories.Default} />

<Controls of={Stories.Default} />

## Conversation drafts

Pass a stable `draftKey` for each conversation. Text, caret position, mentions, and attachments stay with that key when the host switches conversations. A successful submit clears only the accepted text and files, leaving later edits in place.

<Canvas of={Stories.DraftScopes} />

## Clipboard and attachments

Pasting text and a file adds both to one draft. Images and PDFs can be previewed before sending. A failed upload remains in the composer for Retry or Remove; it cannot be sent until resolved.
