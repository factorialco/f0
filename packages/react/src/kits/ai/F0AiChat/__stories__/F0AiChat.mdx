# F0AiChat

Provides the complete One chat surface and accepts host-provided header,
message, input, and overlay content. Use the overlay slot for content that must
temporarily cover the whole chat while remaining scoped to the chat surface.

### Behavior

- WHEN `overlay` or the provider's `chatOverlay` is present → THEN F0 renders
  it above the complete chat surface and makes the chat beneath it inert.
- WHEN both overlay APIs are present → THEN the direct `overlay` prop takes
  precedence.
- WHEN the overlay is removed → THEN the underlying chat becomes interactive
  again.
- The host owns the overlay content, visibility state, actions, and dismissal
  behavior. F0 owns only the scoped backdrop and interaction blocking.

## Accessibility

Overlay content must provide its own semantic structure, accessible name,
focus management, keyboard behavior, and dismissal controls. While an overlay
is mounted, F0 applies `inert` to the chat header, messages, and composer so
they are unavailable to keyboard and assistive-technology navigation.
