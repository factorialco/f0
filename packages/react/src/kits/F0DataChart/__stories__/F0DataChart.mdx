# F0DataChart

Unified chart component. Uses a discriminated `type` prop to select the chart variant.

```tsx
import { F0DataChart } from "@factorialco/f0-react"
```

## Quick Reference

| Type      | Best for                             | Key props                                                  |
| --------- | ------------------------------------ | ---------------------------------------------------------- |
| `bar`     | Comparing categories or time periods | `series`, `categories`, `orientation`, `stacked`           |
| `line`    | Trends over time                     | `series`, `categories`, `lineType`, `showArea`, `showDots` |
| `funnel`  | Conversion pipelines, hiring stages  | `series`, `sort`, `orient`, `showConversion`, `colorScale` |
| `pie`     | Part-of-whole distributions          | `series`, `innerRadius`, `showPercentage`                  |
| `radar`   | Multi-dimensional comparisons        | `series`, `indicators`, `showArea`                         |
| `gauge`   | Single KPI / progress indicator      | `value`, `min`, `max`, `name`                              |
| `heatmap` | Density across two dimensions        | `data`, `xCategories`, `yCategories`, `showLabels`         |
| `scatter` | Relationship between two measures    | `series`, `pointSize`, `scaleAxes`, `xAxisName`            |

All variants share an optional `emptyState` prop — see [Empty states](#empty-states).

## Empty states

When data is empty (empty `series`, empty `data`, or a missing gauge `value`), `F0DataChart` auto-renders a centered message so you never see a bare axis. No prop is required — it is the default behavior. All-zero datasets are **not** empty — `[0, 0, 0]` is a legitimate zero-valued chart and renders as usual.

Default copy is **"No data available"** / **"Try a different date or fewer filters"**.

<Canvas of={EmptyStatesStories.EmptyBar} />

Use the `emptyState` prop to customize copy, replace the UI entirely, or skip detection:

```ts
type F0DataChartEmptyStateProps = {
  title?: string
  description?: string
  /** Render-prop escape hatch — replaces the entire UI. */
  render?: () => ReactNode
  /** Skip empty detection and render the chart as usual. */
  disabled?: boolean
}
```

### Labels, grid density, and overflow

Bar labels use `valueFormatter`, with configurable size and collision handling:

- `labelFontSize` controls label text size.
- `hideOverflowingLabels` hides labels that do not fit instead of allowing overlap.
- `hideAllLabelsOnOverflow` keeps the chart from showing a ragged partial label set.
- `labelFitPadding` controls the clearance used by the fit check.
- `valueAxisSplitNumber` suggests how many value-axis segments and grid lines to draw.

## Scatter Chart

Show the relationship between two measures — one on each axis, one point per entity. Unlike every other cartesian variant there is no category axis: both axes are continuous, so `categories` does not apply. Each point may carry a `label` identifying it, which becomes the tooltip header.

Reach for scatter when the question is "does X relate to Y?". For a trend over time use `line`; for a comparison across categories use `bar`.

Because a point has two coordinates and no third measure, its tooltip has no headline value — both coordinates read as rows, the same shape radar uses for its indicators. Set `xAxisName` and `yAxisName` to label those rows ("salary", "tenure"); without them the rows show bare values.

## Customization

### Value & Category Formatters

Every chart type takes `valueFormatter` for its numbers — axis ticks, labels, and the hover tooltip. One formatter is all most charts need: the tooltip reads the value the way the rest of the chart does, so a unit or a currency can't go missing on hover. Bar and line charts also support `categoryFormatter` for axis labels.

`tooltipValueFormatter` overrides it for the tooltip alone. Reach for it when the axis has to stay compact but the tooltip should be exact:

```tsx
<F0DataChart
  type="line"
  valueFormatter={(v) => `€${(v / 1_000_000).toFixed(1)}M`} // axis: "€4.0M"
  tooltipValueFormatter={(v) => `€${v.toLocaleString()}`} // tooltip: "€4,000,000"
  categoryFormatter={(v) => v.slice(0, 3)}
  // ...
/>
```

With neither, values render as a plain localized number.

<Canvas of={LineStories.CustomFormatters} />

### ECharts Escape Hatch

Bar and line chart types accept an `echartsOptions` prop for advanced customization. Options are shallow-merged on top of the generated config.

```tsx
<F0DataChart
  type="bar"
  echartsOptions={{
    animation: false,
    grid: { left: 80 },
  }}
  // ...
/>
```
