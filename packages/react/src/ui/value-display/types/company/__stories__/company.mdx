### company

Renders a company avatar.

#### Value type

```
type value = {
    name: string
    src?: string // the avatar image
    lines?: number // cap the name at N lines; omit to wrap it in full
}
```

<Canvas
  of={CompanyStories.CompanyType}
  source={{
    code: `
render: (item) => ({
    type: 'company'
    value: {
        name: 'Factorial'
        src: '/pth/to/the/avatar.png'
    }
})
`,
  }}
/>

**Long name inside a fixed-width column**

By default the name wraps onto as many lines as it needs, so the whole name
stays readable however narrow the column is.

<Canvas of={CompanyStories.CompanyTypeWithLongName} />

**Capping how many lines the name takes**

Set `lines` to cap it. The name wraps up to that many lines and truncates with
an ellipsis past them, showing the full name in a tooltip on hover. `lines: 1`
keeps it on a single line — use it where every row has to be the same height.

<Canvas of={CompanyStories.CompanyTypeWithLines} />
