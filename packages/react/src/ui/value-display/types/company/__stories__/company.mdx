### company

Renders a company avatar.

#### Value type

```
type value = {
    name: string
    src?: string // the avatar image
} & (
    | {
        lines?: number
        full?: never
      }
    | {
        lines?: never
        full: true
      }
  )
```

**Long name inside a fixed-width column**

A name wider than its cell truncates with an ellipsis and shows the full name
in a tooltip on hover, the same as the person type.

<Canvas of={CompanyStories.CompanyTypeWithLongName} />

**Controlling how many lines the name takes**

By default the name stays on a single line and truncates with an ellipsis. Set
`lines` to allow more lines before it truncates, or `full` to remove the cap so
the name wraps as far as it needs. The two are mutually exclusive — a name
cannot both stop at N lines and never stop.

Note that `full` also removes the tooltip: it only exists to recover text the
cell has hidden, and a name that wraps in full hides nothing.
