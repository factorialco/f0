# F0StarRating

Captures or displays a rating on a 1-to-`max` star scale. It works as an
interactive control (click, hover-preview or keyboard) and as a read-only
summary that renders fractional averages by partially filling a star. The stars
use the `selected` icon token, because a rating is a selection.

---

# Overview

## Purpose

- Captures a single rating on a discrete 1…`max` star scale.
- Optionally allows half-star (x.5) precision while interacting.
- Displays an existing score — including a fractional average such as 4.3 — as a
  non-interactive summary.
- Ships an accessible, localizable name and full keyboard support out of the box.

## Variants

### Read-only average

A read-only rating fills stars fractionally, so a computed average (e.g. 4.3)
is shown precisely regardless of the `allowHalf` flag.

### Half stars

value; the keyboard steps by 0.5.

# Guidelines

## Design Best Practices

### When to use

- To let a person grant a subjective score, such as feedback or a review.
- To surface an aggregate rating (an average) in a scannable, at-a-glance form.
- When the scale is small and ordinal (typically up to five stars).

### When NOT to use

- For a numeric scale where the exact number matters (e.g. an NPS 0–10): use
  `F0Rating` (numeric tiles) instead.
- For progress toward a goal or a percentage: use `Progress`.
- For a part-to-whole breakdown: use a category bar.

### How to use

- Keep `max` constant across a list so ratings stay comparable.
- Only enable `allowHalf` when half-step precision is meaningful to the user;
  whole stars are simpler to target.
- Reserve fractional values for read-only averages; let interactive input land
  on whole or half stars.

## Content Best Practices

- Provide an accessible name via `ariaLabel` (or `ariaLabelledBy`); a localized
  default is used otherwise.
- Render any surrounding label or helper text yourself — the component renders
  only the stars.

## Accessibility

- Interactive: `role="slider"` with `aria-valuemin`, `aria-valuemax`,
  `aria-valuenow` and `aria-valuetext`; the whole row is a single focusable
  slider.
- Keyboard: ←/↓ decrease and →/↑ increase by one step (0.5 with `allowHalf`,
  otherwise 1); Home selects the lowest star, End the maximum; stepping below
  the minimum clears the rating.
- Read-only / disabled: `role="img"` with an accessible name, no interaction.
- The accessible name is resolved through `useI18n()` and is fully localizable.
