# Info hint

Reveals concise help for the label it follows, so the same measure can explain
itself in a table column, chart, metric, or collection header. This is internal
shared chrome; consumers configure it through the public surface that owns the
label, such as `DashboardItemBase.info`.

### Content forms

**Structured content with a link**

Use a link only when the short explanation leads to a useful source, such as a
catalog entry. Focus or hover the icon to inspect the complete state.

<Canvas of={Stories.Default} />

**Structured content without a link**

Use the same card when a title helps organize the explanation but there is no
destination to offer.

<Canvas of={Stories.DescriptionOnly} />

**Plain text**

Use a string for one short, non-interactive sentence.

### Design best practices

**When to use**

### Behavior

- WHEN `info` is a string → THEN a focusable icon reveals a non-interactive tooltip.
- WHEN `info` is structured content → THEN focus or hover opens a card with its title and description.
- WHEN structured content includes `link` → THEN the card renders the link action and closes after it is activated.
- WHEN `info.label` is present → THEN it overrides the host label and generic accessible-name fallback.
- WHEN no custom accessible name is present → THEN the structured trigger is named “More information”.

## Accessibility

The trigger is keyboard reachable. Give custom labels an action-oriented name,
such as “About active headcount”, rather than repeating the visible heading.
