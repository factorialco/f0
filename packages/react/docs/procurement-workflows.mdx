# Procurement Workflows

The visual editor for building procurement approval flows. A workflow is a canvas of
connected nodes, each one a step a Purchase Request passes through on its way from
submission to a final decision. This page catalogs every node type and the visual
states each one can take.

These previews render the **real** node components from
`frontend/src/modules/workflows/components/Node/` — the same `FlowNodeBasic` card,
category badges, icons, colors and multi-action list used in production. They are
mounted here through a small `NodePreview` wrapper that feeds them a synthetic
ReactFlow node, so what you see is byte-for-byte the editor's own rendering.

## Anatomy

Every node is a colored category badge above a white card. The badge identifies the
node type by color and icon; the card holds a title and a short description.

### Multi-action

A multi-action bundles several actions and approvals that run in parallel. The card
lists each sub-action with its own icon, title and description; the flow continues
only once all of them complete.

<Unstyled>
  <div style={{ padding: "20px 0" }}>
    <NodePreview
      category="multiAction"
      title="Collect documents & checks"
      description="Run document, verification and acknowledgement steps in parallel."
      parallelTasks={[
        {
          type: "task",
          title: "Request invoice",
          description: "Ask the requester to upload the supplier invoice.",
        },
        {
          type: "task",
          title: "Verify budget availability",
          description: "Finance verifies there is budget for this request.",
        },
        {
          type: "approvals",
          title: "Collect supplier details",
          description: "Gather supplier banking and contact information.",
        },
      ]}
    />
  </div>
</Unstyled>

Every node renders in four visual states. The example below shows them on an Approval
node; each node type uses its own category color for the selected and hover borders.
